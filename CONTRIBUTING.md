# Contributing to Skribe

Thanks for your interest in Skribe.

Skribe is an actively developed collaborative whiteboard focused on real-time collaboration, expressive canvas interaction, and structure-aware visual cleanup.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Install the project dependencies.
4. Configure the required environment variables.
5. Start the development environment.
6. Create a branch for your change.

## Before Opening a Pull Request

Please make sure:

- The application builds successfully.
- Relevant tests pass.
- Existing collaboration behavior is preserved.
- Canvas behavior is not unintentionally altered.
- Changes are focused and documented where necessary.

## Contributions

Useful contributions include:

- Bug fixes
- Canvas improvements
- Collaboration improvements
- Accessibility improvements
- New whiteboard primitives
- Mess Cleanup improvements
- Documentation
- Tests

For larger changes, opening an issue first is recommended.

## Questions and Ideas

For larger features or architectural changes, open an issue first so the approach can be discussed before implementation.

Thanks for helping make Skribe better.
