## Loop 11: Fix Preview Fidelity (Missing Text & Freehand Stroke Mutation)

## Loop 12A: Connector Apply Geometry Divergence Fix

### What Changed
Fixed an issue in `executeCleanupPlan.js` where the `center` property of a placement object was not updated when a connector's geometry (bounds and path) was replaced by `cleanFlowchart` or `repairConnector`.

### Why It Changed
The mess cleanup engine accurately computed new coordinates for connectors during cleanup planning, but left the `center` property untouched (retaining the connector's old center from before the cleanup). Because Fabric.js path objects with `originX: 'center'` use this `center` to position the object on the canvas, the `applyCleanup` logic applied the new geometric path but forced its origin to the old stale center. This caused the connector to drift visually on the canvas (e.g., appearing below shapes instead of touching them), resulting in a major discrepancy between the Preview and the Apply phase.

### What It Does
When the bounds and geometry of a connector are explicitly overwritten during `cleanFlowchart` or `repairConnector`, the `center` property is now explicitly recomputed using `bounds.x + bounds.width / 2` and `bounds.y + bounds.height / 2`.

### Impact on Working
Fixes the "Preview -> Apply geometry divergence" bug. The connector is now accurately placed exactly where the Preview logic rendered it, resolving the visual offset issue without altering the actual cleanup logic itself.

### Validation
Verified the fix by running an end-to-end execution trace on the failing dataset. The connector's generated `plan.center` and `appl.left`/`top` now precisely align with the new bounding box (`606, 152.1109`), correcting the previous drift (`693.8546, 232.3969`).
